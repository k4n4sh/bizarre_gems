# Bizarre Gems (в русском каталоге — «Алмазная братва»)

Головоломка на время для Яндекс Игр. Godot 4.7, рендер Compatibility, веб-экспорт без потоков.

Нажми на пустую клетку: игра берёт первый камень в каждом из четырёх направлений, и все камни,
которые встретились хотя бы дважды, выбиваются. 2 камня дают +2 очка, 3 камня +4 и +1 с,
4 камня +6 и +2 с, промах −1 с. На старте 120 секунд. Поле 23×15 (на вертикальном экране 15×23),
270 камней: 10 видов по 27.

## Что есть в игре

- Режимы: «Классика» (оригинальные правила), «Уровни» (главы по 20 уровней со своим фоном,
  боссами с правилом главы и наградами), «Яркий забег», «Шаги», «Головоломка», обучение.
- Особые камни: джокер, ящик, цепь, лёд, бомба с отсчётом, хамелеон.
- Испытание дня (общее поле «Яркого забега», +20 кристаллов в день), сезонный пропуск на 30 ступеней
  (новый сезон каждый месяц), задания, достижения, ежедневный подарок, коллекция из 11 паков плиток,
  статистика, «Лучший удар» в итогах.

## Структура

```
project.godot           настройки (окно 720×720, stretch canvas_items/expand → любой экран)
export_presets.cfg      пресет «Yandex Web»; в html/head_include живёт JS-мост window.YG к SDK
scenes/main.tscn        корневая сцена (UI собирается в scripts/main.gd)
scripts/
  board_logic.gd        правила, без графики (class_name BoardLogic)
  board_view.gd         отрисовка поля, эффекты, ввод мышью/тачем/клавиатурой
  main.gd               состояния игры, интерфейс, реклама, лидерборд
  yandex.gd   (autoload Yandex)  обёртка SDK; вне браузера всё работает как заглушки
  save.gd     (autoload Save)    рекорд и настройки звука: user:// + облако Яндекса
  sfx.gd      (autoload Sfx)     звуки и музыка, глушится на время рекламы
  i18n.gd     (autoload L)       тексты ru / en / tr
assets/                 всё сгенерировано tools/gen_assets.py, шрифты под OFL
tests/test_logic.gd     тесты правил
tools/
  gen_assets.py         пересобирает камни, иконки, текстуры, звуки, иконку и обложку
  serve.py              локальный сервер сборки с имитацией SDK (tools/mock/sdk.js)
store/                  материалы для карточки игры: иконка, обложка, скриншоты, тексты
build.sh                импорт → тесты → экспорт → build/bizarre-gems-yandex.zip
```

## Сборка

```sh
./build.sh                      # нужны godot 4.7 и шаблоны экспорта web_nothreads_*
python3 tools/serve.py          # http://127.0.0.1:8060/  (?lang=en, ?lang=tr)
```

Локально `/sdk.js` подменяется имитацией: реклама показывается заглушкой, в таблице лидеров два
тестовых игрока. В редакторе Godot SDK нет, награда за рекламу выдаётся сразу.

Автоигра для проверки эффектов и скриншотов (только debug-сборка):
`godot --headless --path . --export-debug "Yandex Web" build/webdebug/index.html`, затем
`python3 tools/serve.py 8061 build/webdebug` и открыть `http://127.0.0.1:8061/?autoplay`.

Перегенерировать ассеты: `python3 tools/gen_assets.py` (нужны rsvg-convert, Pillow, numpy).

## Локальный A/B-тест комбо Classic (только debug)

Обычный запуск Classic использует **3,5 с для обычного комбо и 5,0 с для новой
специальной серии** (см. ниже).
Старое сравнение сохранено: в меню или на экране итогов нажмите **F6** для A (3,0 с)
или **F7** для B (3,5 с); оба варианта используют прежнюю специальную серию.
Клавиша сразу начинает новую Classic.
Явные A/B-варианты сохраняют прежние бонусы времени: +2 с за новую ступень
множителя и +3 с за каждый десятый удар. Обычная Classic использует +1 с и +1 с.
Во время игры и паузы переключение запрещено: сначала выйдите в меню. Новых кнопок в UI нет.
В Output появляется `[combo-ab] START` с вариантом, окном, seed и хешем начального поля.

Оба варианта по умолчанию используют seed **42**. Чтобы задать другой seed или сразу выбрать
вариант при запуске, передайте пользовательские аргументы Godot (после `--`):

```sh
godot --path . -- --combo-ab=A --combo-seed=12345
godot --path . -- --combo-ab=B --combo-seed=12345
```

Затем запустите Classic из меню (либо F6/F7). Для F5 те же аргументы можно указать в
Project Settings → Editor → Run → Main Run Args (включите Advanced Settings).
Не меняйте размер/ориентацию окна между сравниваемыми партиями: адаптивная форма поля
сохранена. При одинаковых seed и размерах начальные клетки и `layout_sha256` совпадают.
Генерация, 270 камней, 120 стартовых секунд, базовые очки и продолжения сохранены.

После включения A/B **весь текущий процесс работает без записи пользовательских сохранений
и отправки результатов в лидерборды**. Classic не выдаёт экспериментальные рекорды,
кристаллы, XP или прогресс заданий. Даже после выхода в меню запись остаётся заблокированной.
Для восстановления записи в других режимах перезапустите проект без экспериментальных аргументов.
Обычная Classic сохраняет рекорд и прогресс; блокировка включается только при явном выборе эксперимента.
Release-сборки игнорируют отладочные клавиши и аргументы; обычная Classic в них
сохраняет результаты.

Отчёты дописываются по одной JSON-строке в `user://debug/classic_combo_ab.jsonl` и выводятся
в Output с префиксом `[combo-ab]`. Папку `user://` открывает Project → Open User Data Folder.
Поля отчёта: `score`, `destroyed_gems`, `max_streak`, `combo_breaks`, `hits_at_x4`,
`end_reason`, `time_left`; дополнительно сохраняются вариант, окно, seed, размеры,
хеш расклада, игровое время и использование продолжения/перемешивания.

- Разрыв — потеря уже собранной серии из **2+** ударов из-за промаха или истечения окна;
  одиночный удар и завершение партии разрывом не считаются.
- `hits_at_x4` включает каждый успешный удар с ×4, начиная с девятого удара серии.
- Причины: `time`, `stuck` (в том числе полная очистка, как в исходной игре),
  `restart`, `abandoned`, `quit`. Принудительная остановка процесса редактором/ОС
  может не дать записать `quit`; для отчёта незаконченной партии сначала выйдите в меню.
- После продолжения/перемешивания следующий итог имеет тот же `run_id`, увеличенный
  `result_index` и накопительные показатели. Для сравнения исходной партии берите первый итог.
- Автоматический A/B-тест помечает свои отчёты `automated_test: true`.

Проверки: `godot --headless --path . --script res://tests/test_logic.gd`;
через Godot AI MCP `game_eval` на свежем главном меню:

```gdscript
return load("res://tests/test_strike_accounting.gd").new().run_suite(get_tree().current_scene)
# Затем A/B (он оставляет процесс в режиме без сохранений):
return load("res://tests/test_combo_ab.gd").new().run_suite(get_tree().current_scene)
```

## Специальная серия Classic: эксперимент 5 секунд

Обычная Classic использует окно **3,5 с** для обычного комбо и отдельное начальное
окно **5,0 с** для новой специальной серии.
Обычное поле остаётся случайным. Для повторяемого сравнения в меню/итогах:

| Клавиша | Обычное окно | Специальная серия | Seed |
| --- | --- | --- | --- |
| F6 | 3,0 с | Прежняя, строго подряд | 42 по умолчанию |
| F7 | 3,5 с | Прежняя, строго подряд | тот же |
| N | 3,5 с | Новая, отдельный таймер | тот же |

Для сравнения только специальной механики используйте **F7 и N**. Переключение во время
партии/паузы запрещено. Аргументы для своего seed:

```sh
godot --path . -- --special-combo=legacy --combo-seed=12345
godot --path . -- --special-combo=timed --combo-seed=12345
```

После запуска выберите Classic. Явный эксперимент `--special-combo` выбирает 3,5 с;
при необходимости его можно совместить с `--combo-ab=A` или `B`.
F6/F7 всегда возвращают старую специальную
механику, N включает новую при 3,5 с. Эти отладочные варианты не меняют стандартную
конфигурацию обычного запуска: 3,5 с / 5,0 с. Явные эксперименты сохраняют прежние
бонусы +2 с за ступень и +3 с за каждый десятый удар.

Оба таймера используют `play_time`, который идёт только в PLAYING. Обычное комбо
сбрасывается при интервале **строго больше** окна (сохранена прежняя граница).
У специальной серии отдельный срок `_special_deadline`: 3+ камня устанавливают его
в `play_time + 5`; каждая пара прибавляет **ровно 0,5 с без каких-либо лимитов**,
не увеличивая число специальных действий. При остатке **0 с** специальная серия уже
истекла: сначала проверяется истечение, затем обрабатывается удар. Поэтому пара её
не воскрешает, а новая тройка начинает новый цикл.

Третье специальное действие даёт Precise (+10 очков, +3 с), четвёртое — Perfect
(+20 очков, +5 с) и сбрасывает только специальный цикл. Обычное комбо продолжается.
Промах и разрыв обычного комбо обнуляют оба прогресса; самостоятельное истечение
специального таймера не сбрасывает обычный множитель. Пауза останавливает оба таймера.
Видимый второй таймер не добавлен; поздравления и награды сохранены.

Bright и Daily остаются на прежней специальной системе и прежнем обычном окне.
Обычная Classic сохраняет результаты с текущими правилами 3,5 с / 5,0 с.
Блокировка записи сохранений и онлайн-результатов включается только при явном
отладочном выборе через F6/F7/N или экспериментальные аргументы и действует до
выхода из процесса. После такого эксперимента перезапустите игру для записи прогресса.

Журнал `user://debug/classic_combo_ab.jsonl` дополнен полями `special_rules`,
`precise_events`, `perfect_events`, `special_bonus_points`, `special_bonus_time`.
`seed: null` означает обычную случайную генерацию. Наградные секунды в отчёте —
только фактически начисленный специальный бонус, без базовых секунд/сверкания/ступеней.
Отчёты искусственных игровых последовательностей помечаются `fixture_test: true`.

Новые автоматические проверки через Godot AI MCP на свежем меню:

```gdscript
var tests = load("res://tests/test_special_combo.gd").new()
return {"rules": tests.run_rules(), "runtime": tests.run_in_game(get_tree().current_scene)}
```

Симуляция работает небольшими порциями в отдельном дочернем Node, чтобы не блокировать MCP:

```gdscript
var sim = load("res://tests/simulate_special_combo.gd").new()
sim.name = "SpecialComboSimulation"
get_tree().current_scene.add_child(sim)
sim.call_deferred("run_all", 1, 100)
return "started"
# Позже: у узла доступны done, completed_seeds и results.
```

Методика, результаты и ограничения модели: [отчёт](reports/special_combo_balance.md).

## Баланс времени обычной Classic

Стартовый запас — **120 с**, обычное окно комбо — **3,5 с**. Пороги множителей
сохранены: ×2 со второго успешного удара, ×3 с пятого, ×4 с девятого.

| Награда | Время |
| --- | --- |
| Новая ступень ×2, ×3 или ×4 | +1 с за каждую |
| Удар №10, 20, 30 и далее в непрерывной серии | +1 с за каждый |
| 2 камня / 3 камня / 4+ камня | 0 с / +1 с / +2 с |
| Precise / Perfect | +3 с / +5 с |
| Каждый сверкающий камень | +2 с |

Награды одного удара складываются один раз: например, Perfect на десятом ударе
с четырьмя камнями и двумя сверкающими даёт **2 + 5 + 1 + 4 = 12 с**.
Особая серия сохраняет отдельное окно 5 с; пары добавляют к нему 0,5 с без
увеличения счётчика уникальных действий. Bright Run, Daily и остальные режимы
сохраняют прежние правила времени. Продолжения и перемешивание не изменены.

Короткая проверка правил и реального начисления через `_on_slot`:
`godot --headless --path . --script res://tests/run_runtime_suite.gd -- --suite=test_classic_balance`.
Запускайте в изолированной копии, созданной через `tests/test_mode_records.ps1`
(с путями сохранений `res://.test-user/`): тест проверяет обычную Classic
без включения экспериментальной блокировки сохранений.

## Тестовая сборка для Android

```sh
./build_android.sh              # build/android/bizarre-gems-debug.apk, ставит на телефон через adb
```

Нужны шаблоны Godot `android_debug.apk`/`android_release.apk`, Android SDK в `~/Android/Sdk`
(build-tools, platform-tools) и JDK, указанный в настройках редактора
(`export/android/java_sdk_path`). APK подписан debug-ключом, это сборка только для проверки.
Пакет `com.electrocrem.bizarregems`, экран поворачивается по датчику, «Назад» ставит паузу и
закрывает окна, из меню выходит из игры. SDK Яндекса на Android нет: реклама за награду
выдаётся сразу, межстраничной нет, таблица лидеров пишет, что работает в Яндекс Играх.

## Загрузка в Яндекс Игры

1. Консоль разработчика: https://games.yandex.ru/console → «Добавить приложение».
2. **Лидерборды**: раздел «Лидерборды» → создать четыре с техническими названиями `score` («Классика»),
   `score_bright` («Яркий забег»), `score_zen` («Шаги») и `stars` («Звёзды уровней»)
   (по убыванию, тип «число»). Без них таблицы будут пустыми.
3. Архив: «Черновик» → загрузить `build/bizarre-gems-yandex.zip` (index.html в корне архива).
4. Иконка 512×512: `store/icon_512.png`. Обложки 800×470 для каждого языка: `store/cover_800x470_ru.png`, `_en.png`, `_tr.png`.
   Скриншоты: `store/screenshots/` (1920×1080 и 1079×1918).
5. Тексты и SEO для полей карточки: `store/listing.md` (проверка лимитов: `python3 tools/check_listing.py`).
6. Языки: русский, английский, турецкий. Платформы: десктоп и мобильные, обе ориентации.
7. Реклама: межстраничная перед «Ещё раз» (не чаще раза в 61 с), за вознаграждение:
   +15 секунд после конца времени или перемешивание, когда ходов нет (по разу за партию и уровень),
   ×2 кристаллы в итогах партии или уровня, подсказка после бесплатной и подсказок из пропуска.

Что уже сделано под требования Яндекса: `LoadingAPI.ready()` после загрузки, `GameplayAPI.start/stop`
вокруг активной игры, пауза и выключение звука при рекламе, при сворачивании вкладки и по
событиям `game_api_pause/resume`, язык из `ysdk.environment.i18n.lang`, сохранения в облаке
игрока, контекстное меню и выделение текста отключены.
